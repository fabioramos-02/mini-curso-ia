# Relatórios com IA — mini curso SGD

Mini curso da Superintendência de Governo Digital (SGD/SETDIG) para o time gerar relatórios em
HTML com IA, no padrão do Design System de MS.

- Site: https://fabioramos-02.github.io/mini-curso-ia/
- Slides: https://fabioramos-02.github.io/mini-curso-ia/slides/

## Rodar localmente

```bash
pip install -r requirements.txt
mkdocs serve
```

Os slides ficam em `docs/slides/index.html` (reveal.js 5 via CDN) e são publicados junto com o
site. O exemplo de relatório (`docs/exemplos/`) usa dados fictícios.

A publicação é automática: todo push na `main` roda o workflow `gh-pages.yml`.
