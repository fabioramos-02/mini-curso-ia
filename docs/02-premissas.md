# 2. As 4 premissas

Antes de gerar qualquer relatório, responda quatro coisas. Se uma delas estiver em branco, o
relatório sai fraco.

| # | Premissa | Pergunta que ela responde |
|---|---|---|
| 1 | **Perguntas** | Para quem é, para quê e qual decisão ele ajuda a tomar? |
| 2 | **Prompt base** | Como eu peço, sempre do mesmo jeito? |
| 3 | **Dados** | Quais dados entram, de onde vêm e o que fica de fora? |
| 4 | **Estrutura** | Como o HTML se organiza, seguindo o Design System? |

## 1. Perguntas

O relatório começa pela pessoa que vai ler, não pelos dados.
Veja [as perguntas](03-perguntas.md).

## 2. Prompt base

Um texto fixo que você copia, cola e só troca a parte dos dados.
Veja [o prompt base](04-prompt-base.md).

## 3. Dados

A IA só pode usar o que você entregar. Dado errado gera relatório errado.
Veja [os dados](05-dados.md).

## 4. Estrutura

Um esqueleto fixo de seções, com as cores e fontes do Design System.
Veja [a estrutura](06-estrutura-ds.md).

!!! tip "Regra de bolso"
    Pergunta clara + dado certo + prompt base + estrutura fixa = relatório que você confia.
