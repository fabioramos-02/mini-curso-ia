# 9. Próximos passos

Este curso para no HTML pronto. Quando o time estiver seguro com ele, os próximos passos são:

## Publicar

Hoje você envia o arquivo `.html` por e-mail ou chat. Depois, dá para publicar com um link:

- **GitHub Pages:** o relatório vira uma página com endereço fixo.
- **Artifact do Claude:** a própria IA publica uma página privada que você compartilha.

## Usar sempre o mesmo modelo

Guarde o HTML que ficou bom. Na próxima vez, mande o arquivo antigo junto com os dados novos e
peça: "mantenha este layout e troque só os dados".

## Automatizar

Ligar a IA direto nas fontes (TFS, BI) para o relatório sair com um comando, sem copiar e colar.

!!! note "Um passo de cada vez"
    Primeiro, todo mundo gera o HTML com confiança. Publicar e automatizar vêm depois.
