Relatórios com IA

Do pedido ao HTML pronto, no padrão do Governo de MS

Mini curso · Superintendência de Governo Digital (SGD)

O que você leva daqui

Pedir à IA um relatório e receber um arquivo HTML pronto, que abre no navegador e segue o Design System de MS.

Sem programar. Sem instalar nada.

Hoje cada um faz de um jeito

  • Texto num relatório, tabela no outro, slide no terceiro
  • Cores e fontes fora do padrão
  • Número inventado pela IA para "completar"
  • Ninguém sabe de onde veio cada dado

A ideia central

A IA monta rápido.
Você responde pelo que está escrito.

As 4 premissas

Perguntas · Prompt base · Dados · Estrutura

1Perguntas

  • Quem vai ler?
  • Para quê?
  • Qual decisão ele ajuda a tomar?
  • Qual período? Qual tamanho?
  • O que aparece primeiro?

Não sabe responder? Pare e pergunte a quem pediu.

2Prompt base


Você vai montar um relatório em HTML para a SETDIG, Governo de MS.

# Contexto
- Quem vai ler: [quem]   - Para quê: [objetivo]
- Decisão: [decisão]     - Período: [período]

# Regras
1. Use SÓ os dados abaixo. Não invente. Faltou? "a confirmar".
2. Linguagem simples.
3. Devolva UM arquivo HTML completo, CSS dentro de <style>.
4. Só as variáveis --ds-* do Design System para cor e espaço.
5. Mulish nos títulos, Open Sans no texto.
6. Links em nova aba. 7. Funciona no celular.

# Estrutura
Faixa azul · Destaques · Detalhe · Atenção · Rodapé SETDIG

# Dados
[cole aqui]

Texto completo, com as cores, na página "Prompt base" do site.

A regra mais importante

"Use SÓ os dados que eu entreguei. Não invente número, nome ou data."

Sem ela, a IA preenche o que falta, e o erro vai com a sua assinatura.

3Dados

Leve
  • Só o período
  • Só as colunas úteis
  • Fonte e data
Nunca leve
  • CPF, telefone, endereço
  • Senha, token
  • Dado sigiloso

Precisa do número? Mande o total, não a lista de pessoas.

4Estrutura

Faixa azul: título · período · números
Destaques: cards numerados
Detalhe: listas ou tabela por tema
Atenção: riscos e pendências
Rodapé SETDIG

As cores dizem algo

Azul: marca e links
Verde: concluído
Laranja: em andamento
Vermelho: bloqueado

Toda cor vem de uma variável --ds-*.

Um relatório semanal, do começo ao fim

Checklist antes de enviar

  • Cada número está nos dados
  • A contagem bate
  • Nada de "a confirmar" esquecido
  • Sem dado pessoal
  • Cores do Design System, abre no celular
  • Links funcionam e abrem em nova aba

Ajustes: um de cada vez

"Deixe os cards em duas colunas."
"Mova a seção Atenção para o topo."
"Melhore tudo."

Pedido amplo faz a IA mexer nos números.

Depois deste curso

  • Reaproveitar: mande o HTML antigo e peça "troque só os dados"
  • Publicar: GitHub Pages ou Artifact, com um link
  • Automatizar: IA ligada direto no TFS e no BI
